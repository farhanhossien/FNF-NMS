# Phase 02-01: Fiber Monitoring Integration Plan

**Goal**: Connect to OLTs via SNMP and read optical signal metrics.

## Step 1: Install SNMP Library
- Run `npm install net-snmp` to add SNMP support for Node.js.

## Step 2: Configure Environment Variables
- Add OLT IP and SNMP Community string to `.env` and `.env.example`.
- Update `src/config/env.js` to validate and export `OLT_IP` and `OLT_SNMP_COMMUNITY`.

## Step 3: Implement OLT Service (`src/services/olt.js`)
- Create `src/services/olt.js` to manage SNMP polling.
- Implement an initialization function `initOltSession()`.
- Implement `pollOltMetrics()` which uses SNMP `get` or `walk` to fetch ONU RX/TX power levels. (Mock or actual implementation using common OLT OIDs).
- Implement threshold detection to log warnings when signal drops below -27dBm.

## Step 4: Unit Testing
- Write `tests/olt.test.js` using Node.js built-in `node:test` and `node:assert`.
- Mock `net-snmp` to return dummy signal levels.
- Test normal levels (e.g., -20dBm) and weak levels (e.g., -28dBm).

## Step 5: Integration
- Update `src/index.js` to initialize the OLT service alongside MikroTik.
- Periodically poll OLT metrics in the main loop.
