# Phase 03-01: Dashboard & Alerts Plan

**Goal**: Visualize the data and notify the team of critical issues via Telegram.

## Step 1: Telegram Alert Integration
- Run `npm install node-telegram-bot-api`.
- Add `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` to `.env.example` and `src/config/env.js`.
- Create `src/services/telegram.js` with methods `sendAlert()` and `sendRecovery()`.
- Add state tracking to avoid spamming alerts.

## Step 2: Real-time Dashboard Server
- Run `npm install express socket.io`.
- Create `src/server.js` to serve static files and initialize Socket.io.
- Create a stunning, modern dark-themed UI in `public/index.html`, `public/style.css`, and `public/app.js`.
  - Use glassmorphism and modern fonts (e.g. Inter).
  - Show Core Router health/traffic and Fiber ONU status in a beautiful grid.

## Step 3: Wiring
- Modify `src/index.js` to run a continuous polling loop (e.g., every 10 seconds).
- Integrate the Express server to start on port 3000.
- Pass fetched MikroTik and OLT data to the Socket.io server to broadcast to the UI.
- Trigger Telegram alerts on downtime or weak signals.

## Step 4: Unit Testing & Verification
- Test telegram service and verify dashboard runs.
