# Phase 1 Plan 1: MikroTik Core Router Integration

## Goal
Implement the initial connection and data fetching logic to authenticate with a MikroTik core router and retrieve health and traffic metrics.

## Context
- **Phase**: 1
- **Requirements Covered**: CORE-01, CORE-02, CORE-03
- **Target Files**: `package.json`, `src/config/env.js`, `src/services/mikrotik.js`, `src/index.js`

## Tasks

1. **Project Setup**
   - Initialize a Node.js project.
   - Install required packages: `dotenv` for environment variables, `node-routeros` (or similar) for MikroTik API interaction.
   - Set up `.env.example` with `MIKROTIK_HOST`, `MIKROTIK_USER`, and `MIKROTIK_PASS`.

2. **MikroTik Service Module**
   - Create `src/services/mikrotik.js`.
   - Implement a function to establish a connection to the router using the API (default port 8728).
   - Add error handling for connection timeouts or invalid credentials.

3. **Fetch System Resources (Health)**
   - Implement a function `getSystemResources()` inside the mikrotik service.
   - Use the API command `/system/resource/print` to get CPU load, free memory, total memory, and uptime.

4. **Fetch Interface Traffic (Bandwidth)**
   - Implement a function `getInterfaceTraffic(interfaceName)` inside the mikrotik service.
   - Use the API command `/interface/monitor-traffic` to read the `rx-bits-per-second` and `tx-bits-per-second`.

5. **Main Entry Logic**
   - Create `src/index.js` to tie it all together.
   - Connect to the router, fetch both system resources and interface traffic, and print the results to the console.
   - Disconnect cleanly.

## Definition of Done
- The Node.js script successfully connects to a MikroTik router.
- Health metrics and bandwidth data are accurately fetched and printed to the console.
- Connection is cleanly closed.
- Environment variables are used for all sensitive credentials.
